# 请求脱敏

在网关把请求发往上游之前，替换请求文本中的个人信息和密钥，让模型看不到这些内容。也可以在模型回复中遮盖同类信息。

## 添加方法

1. 在控制台打开“请求处理”，点击“添加”。
2. 选择“请求脱敏”，填写“设置”。
3. 在“用在哪里”选择“所有请求”、“指定分组”或“只在渠道添加”。选“只在渠道添加”时，还要在渠道设置的“请求处理插件”里加上这个实例。“模型”可以限定只对部分模型生效。
4. 保存。编辑时可以用“试一试”对比示例请求脱敏前后的内容；“请求处理”页面的“试运行”会运行已保存的实例。

## 设置

- **内置类型**：要替换的信息类型。除 IPv4 地址外默认全部开启。
  - **邮箱地址**。
  - **电话号码**：中国大陆手机号，以及以 `+` 开头的国际号码。
  - **身份证号**：校验位正确的中国大陆居民身份证号。
  - **银行卡号**：通过卡号校验位检查的卡号。
  - **API 密钥和令牌**：`sk-...` 这类密钥，AWS、Google、GitHub 和 Slack 的密钥，以及 `Bearer` 后面的令牌。
  - **IPv4 地址**：默认关闭，因为版本号和示例地址看起来一样。以 `127.` 或 `0.` 开头的地址不会被替换。
- **自定义规则**：最多 50 条正则表达式，在内置类型之后应用。每条规则可以设置自己的“替换文本”和“规则 ID”。无法编译的表达式在保存时就会被拒绝。
- **默认替换文本**：替换每处匹配的文本，默认 `[REDACTED]`。
- **发送前检查**：“拒绝请求”（默认）或“关闭”，说明见下文。
- **遮盖回复**：默认关闭。开启后，模型回复中命中同样类型和规则的内容也会被遮盖。

## 脱敏范围

- Chat Completions、Responses、Claude Messages 和 Gemini 请求中消息、系统提示词和 instructions 的文本。
- 文本补全和图片生成请求的 prompt，以及 Embedding 请求的输入。
- 视频、音乐生成等任务提交和 Midjourney 提交的提示词、反向提示词和歌词。
- 请求里直接附带的文本文件。PDF 和 DOCX 文件可以读取，但无法修改。

## 对客户端的影响

- 模型收到的是脱敏后的文本，所以回答里可能出现替换文本。
- “发送前检查”为“拒绝请求”时，网关会拒绝无法完全脱敏的请求：含有此类信息的 PDF 或 DOCX 文件，或者最终请求体里仍有此类信息（例如渠道参数覆盖添加的内容）。客户端收到 HTTP 400、错误码 `request_rejected` 和提示“请求被策略拒绝 (code: sensitive_content)”。
- “发送前检查”为“关闭”时，这些请求按原样发送。
- 开启“遮盖回复”后，回复中的每处匹配会替换为 `***`。流式回复最多缓冲 128 个字符，以便找到跨数据块的匹配。
- 使用日志会显示替换了哪些类型以及次数，不会记录原文。
- 插件处理某个请求出错时，请求失败，返回 HTTP 500 和错误码 `request_plugin_failed`。

## 限制

- 不处理工具调用参数、工具声明和图片。
- 回复遮盖只覆盖 Chat Completions、Responses、Claude Messages 和 Gemini 回复里的文本，不处理任务结果、图片和音频。
- 需要 new-api v1.0.0-rc.50 或更高版本。
